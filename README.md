# Noori releases

Downloads and the update feed for **Noori**, a lightweight macOS app that turns the MacBook notch into an iPhone-style island: now playing with synced lyrics, live activities, volume and brightness HUDs, Bluetooth and battery.

## Download

Get the latest `Noori-<version>.zip` from [Releases](https://github.com/wenujacodes/Noori-releases/releases/latest), unzip it and move **Noori.app** to Applications.

Noori isn't notarized yet, so the first time you open it macOS says it's from an unidentified developer: right-click **Noori.app**, choose **Open**, then **Open** again. After that, Noori updates itself (Noori › Check for Updates…).

Requires macOS 14.6 or later.

## Update feed

`appcast.xml` is the [Sparkle](https://sparkle-project.org) feed installed copies check for new versions. Each update is signed with Noori's own key.
